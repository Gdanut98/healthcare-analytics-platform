# Public Repository Standard

A flagship repository is considered publishable when a technical reviewer can inspect:

- the business problem and analytical objective,
- data provenance and privacy/redistribution constraints,
- executable SQL/Python/model logic,
- environment or dependency instructions,
- data preparation and feature logic,
- model/schema grain and assumptions,
- validation/data-quality checks,
- quantitative outputs,
- visual evidence,
- limitations,
- source-vs-refactor provenance,
- a reproducible run order.

## Status meanings
- **Source-derived:** from submitted graduate work.
- **Refactored:** same analytical logic reorganized for clarity/reproducibility.
- **Reconstructed:** recreated from source evidence when the original executable artifact is unavailable.
- **Portfolio extension:** new work intentionally added after the course.
