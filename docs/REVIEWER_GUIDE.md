# Technical Reviewer Guide — Healthcare Analytics Platform

## What to inspect
1. Read the main README for the business question and headline evidence.
2. Read `docs/PROVENANCE.md` to distinguish original coursework from later portfolio work.
3. Inspect source/notebook/SQL folders for implementation.
4. Inspect quality/validation documentation before relying on metrics.
5. Read limitations and interview notes for interpretation boundaries.

## What this repository is not
It is not intended to inflate coursework into professional client work. Its purpose is to make graduate technical evidence inspectable and to show how the work can be engineered into a stronger modern portfolio artifact.
