# Provenance — Healthcare Analytics Platform

This repository's academic foundation comes from CIS 505 assignments covering healthcare ER modeling, SQL, a healthcare star schema/data marts, and Tableau. The BigQuery-oriented ELT implementation, synthetic source system, expanded fact design, reconciliation framework, and Power BI specification are portfolio extensions built after the course.

## Public inspection rule
Every quantitative claim should trace to an executed/source artifact. New code added for portfolio presentation must be identified as refactoring, reconstruction, or extension rather than silently presented as the original submission.
